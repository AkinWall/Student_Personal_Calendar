# Development Process

## Process Model

Our team is using Scrum as our Agile process model for The Gallifreyan Student Scheduler.

## GitHub Project Board

We are using GitHub Projects to manage our Scrum backlog and track our progress.

[GitHub Scrum Board](https://github.com/users/AkinWall/projects/1/views/1)

## Board Workflow

Our Scrum board uses three columns:

- Backlog
- In Progress
- Done

New tasks are added to the Backlog. When work begins on a task, it will be moved to In Progress. Once the task is completed, it will be moved to Done.

## Sprint 1

**Length:** 2 weeks

**Dates:** October 5–October 18, 2026

**Sprint Goal:** Create basic calendar and event management functionality.

### Sprint Backlog

- As a student, I want to view my calendar so that I can see my schedule.
- As a student, I want to create, edit, and delete events so that I can manage my schedule.
- As a student, I want to add times and locations to events so that I know when and where they take place.
