# Student_Personal_Calendar
A general use school calendar for university students. This calendar will automatically schedule events, specify holidays, indicate which days there will be no class in session due to a holiday, and function with times and places, like the retired SEMO "Week at a Glance" page. With this, we can also add the ability to incorporate club events and campus events they're interested in, and automate how often to schedule something at a set interval (such as 4 or 5 days), scheduling it every 4 or 5 days from then on. Finally, it could also have an easy-to-edit, highly customizable interface, the ability to invite collaborators, and the ability to set triggers based on a specific date or time (such as launching an app or opening a page for a specific assignment).
